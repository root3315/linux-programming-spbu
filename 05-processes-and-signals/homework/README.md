# ДЗ 5. Своя маленькая оболочка

## Условие

Сдаётся архив `proc-homework.tar.gz`: исходники и `report.txt` с командами и выводом.

1. Написать `minishell.c`: читает строку, делит её по `|` и запускает конвейер из двух
   команд.
2. Добавить обработчик `SIGINT`: Ctrl+C не убивает оболочку, а печатает новое приглашение.
3. Сделать встроенную команду `cd` (через `chdir`, без `fork`).
4. Добиться, чтобы после выхода из minishell не оставалось зомби.
5. Прогнать `zombie-finder.sh` до и после и приложить вывод.
6. Описать в `report.txt`, где именно закрываются дескрипторы и почему.

Порядок в отчёте: как устроен разбор строки, где создаются процессы, где закрываются
дескрипторы, вывод `zombie-finder.sh`, что было непонятно.

## Критерии

Базовый: `ls | wc -l` внутри моей оболочки даёт тот же ответ, что и в bash, зомби не
остаётся. Выполнен: в отчёте `ls /etc | wc -l` в minishell и в bash дают 112,
`zombie-finder.sh` до, во время и после работы пишет «зомби не найдено».

Продвинутый: работают `cd`, `exit` и перенаправление `> файл`, Ctrl+C не ломает оболочку,
есть Makefile с целью `clean`. Выполнен: всё это есть в сессии из отчёта, Ctrl+C нажимал
в настоящем терминале и посылал `kill -INT` из второго. Сверх условия конвейер берёт до
8 команд, а не только две, и есть `make test` с проверками и сборкой под ASan.

## Как собрать

В контейнере с Ubuntu 24.04:

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
apt update && apt install -y build-essential procps
```

```bash
make            # ./minishell
make asan       # ./minishell-asan с AddressSanitizer и UBSan
make test       # test.sh на обеих сборках
./minishell
make clean
```

Чего minishell не умеет: кавычки, переменные, `~`, `&`. Из перенаправлений есть только
`> файл` (можно слитно, `>файл`), одно на команду и не у встроенных. На `<`, `>>`, `2>`,
`ls>out`, второе `>`, `cd > f`, а также на `cd` или `exit` внутри конвейера оболочка
пишет ошибку и ставит код 2, а не пытается угадать. `exit abc` выходит с кодом 2,
`exit 1 2` не выходит, как в bash. Ctrl+\ в интерактивном режиме игнорируется.

## Как сделать архив

```bash
make dist
```

Цель запускает `md2txt.sh` (заголовки подчёркнуты `===` и `---`, код с отступом в два
пробела) и пакует каталог `proc-homework/` с исходниками и `report.txt`. Сам `report.txt`
создаётся только во временном каталоге внутри `dist`. Сначала он собирался рядом с
исходниками, и при проверке архива `make clean` в распакованной копии стёр его вместе с
бинарниками. Архив проверил в чистом `ubuntu:24.04`: распаковал, поставил пакеты выше,
`make` и `make test` прошли.
