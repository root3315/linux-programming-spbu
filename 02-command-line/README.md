# Лекция 2. Работа с командной строкой

Чем терминал отличается от оболочки, что такое POSIX, как устроено дерево каталогов, как
создавать, искать и удалять файлы, как управлять процессами и фоновыми заданиями, как
выжить в nano и vi и где искать справку. Отдельного практикума у этого занятия нет: задание
со слайда «Практическое задание» и есть домашка.

## Что внутри

- [notes.md](notes.md) — конспект лекции, [notes.pdf](notes.pdf) — он же в PDF;
- [homework/](homework/) — ДЗ: [условие](homework/README.md), [отчёт](homework/REPORT.md),
  `history` и `ls -la project` из сессии, архив `cli-homework.tar.gz`.

## Как запустить

Всё делал в контейнере с Ubuntu 24.04:

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
apt update && apt install -y nano vim-tiny procps
```

Архив для сдачи пересобирается из каталога `homework/` командой `./dist.sh`.
