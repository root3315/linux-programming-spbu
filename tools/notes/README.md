# Сборка конспектов в PDF

Конспект каждого занятия лежит в `notes.md`. Скрипт `build.py` собирает из него `notes.pdf`:
переводит Markdown в HTML, оформляет стилем `style.css` и печатает в PDF через Chrome
в режиме headless.

## Как собрать

Нужны Python 3.10+ и Google Chrome или Chromium версии 131 или новее: более старые не умеют
колонтитулы.

```bash
pip install -r tools/notes/requirements.txt
python tools/notes/build.py 04-build-toolchain/notes.md   # один конспект
python tools/notes/build.py --all                         # все сразу
```

Если Chrome стоит не в стандартном месте, путь задаётся переменной `CHROME`:

```bash
CHROME=/usr/bin/chromium python tools/notes/build.py --all
```

## Что писать в notes.md

В начале файла нужен блок с номером лекции и темой, из него собирается шапка:

```markdown
---
lecture: 4
title: Сборка программ в Linux
summary: Препроцессор, компилятор, линковщик, Make и CMake.
---
```

Дальше обычный Markdown: заголовки `##` и `###`, списки, таблицы, блоки кода с языком.
Цитата, которая начинается с жирной метки «Запомнить» или «Грабли», становится врезкой:

```markdown
> **Запомнить:** короткое правило, которое нужно знать на зачёте.

> **Грабли:** ошибка, на которой я сам застрял.
```

## Оформление

Колонтитулы сделаны как у man-страниц: `LEC04(7)` слева и справа, название курса по центру.
Шрифты: PT Serif для текста, IBM Plex Sans для заголовков, JetBrains Mono для кода. Все три
распространяются по лицензии SIL Open Font License, тексты лицензий лежат в `fonts/`.

Я урезал шрифты до латиницы и кириллицы, чтобы они весили мало. Лицензия запрещает
называть изменённую версию исходным именем, поэтому урезанные PT Serif и IBM Plex Sans
лежат под именами Notes Serif и Notes Sans. У JetBrains Mono такого ограничения нет.
