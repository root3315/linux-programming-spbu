Вводная лекция курса: что делает ядро, откуда взялись UNIX, MINIX и GNU, как в 1991 году
появился Linux, как из него выросли дистрибутивы и где он работает сейчас. Заодно
преподаватель рассказал формат курса: 16 часов лекций, 24 часа практики, в конце зачёт.

## Как проверить команды из конспекта

В конспекте пять команд: они показывают дистрибутив, ядро и версии GNU-утилит. Вывод в
конспекте из моего образа на Ubuntu 24.04. В чистом `ubuntu:24.04` всё запускается так же,
отличаться может только номер сборки пакетов (у glibc я видел `8.9` вместо `8.12`):

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
cat /etc/os-release
uname -a
bash --version | head -1
ldd --version | head -1
ls --version | head -1
```

Ставить ничего не нужно, всё есть в базовом образе. Как запускать контейнер, написано в
[CONTRIBUTING.md](../CONTRIBUTING.md).
