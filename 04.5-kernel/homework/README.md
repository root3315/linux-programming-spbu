# ДЗ 4.5. Паспорт своей машины

## Условие

Собрать отчёт о ядре своей или учебной машины. Только чтение: ничего не запускать с `sudo`,
ничего не собирать и ничего не «исправлять». Шесть пунктов:

1. `uname -r` и `uname -a`: версия и сборка.
2. Три любые опции `CONFIG_` из `/boot/config-$(uname -r)`: одна `=y`, одна `=m`, одна
   `is not set`.
3. Сколько модулей загружено (`lsmod`) и сколько всего лежит в `/lib/modules`.
4. `modinfo` любого модуля: файл, лицензия, зависимости.
5. Своя строка `/proc/cmdline` с разбором каждого параметра.
6. Пять последних строк `dmesg` и что они значат.

Имени архива на слайде нет, я назвал его `kernel-homework.tar.gz`.

## Критерии

Базовый: отчёт на одну страницу, все шесть пунктов, команды и их вывод, короткое объяснение
своими словами. Выполнен: разделы 1–6 в [REPORT.md](REPORT.md).

Продвинутый: ответ на вопрос «Почему ядро нельзя править на живой системе?», три причины, у
каждой пример последствия. Выполнен: раздел «Почему ядро нельзя править на живой системе» в
том же отчёте.

## Что где лежит

| Файл | Что это |
|---|---|
| [passport.sh](passport.sh) | собирает все шесть пунктов, только чтение, без sudo |
| [passport.txt](passport.txt) | вывод `passport.sh` на моей машине (WSL2, Ubuntu 24.04) |
| [REPORT.md](REPORT.md) | отчёт: вывод по пунктам, разбор, ответ на вопрос |
| [dist.sh](dist.sh) | делает `report.txt` из `REPORT.md` и собирает архив |
| `kernel-homework.tar.gz` | архив для сдачи: `passport.sh`, `passport.txt`, `report.txt` |

## Как запустить

`passport.sh` надо запускать на настоящей машине или в WSL, от обычного пользователя:

```bash
./passport.sh > passport.txt
./passport.sh tls            # modinfo другого модуля вместо br_netfilter
```

Если `/boot/config-*` нет, скрипт берёт конфиг из `/proc/config.gz`. Если `dmesg` не
отвечает, пробует `journalctl -k`. В Docker-контейнере скрипт отработает, но половина
пунктов будет пустой: модулей в контейнере нет, а `dmesg` без `CAP_SYSLOG` не читается.

## Как собрать архив

Архив собирается где угодно, хоть в контейнере с Ubuntu 24.04:

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
./dist.sh
tar tzf kernel-homework.tar.gz
```

В архиве каталог `kernel-homework/` со скриптом, его выводом и `report.txt` (тот же
REPORT.md простым текстом). Проверка скриптов: `apt install -y shellcheck`, потом
`shellcheck passport.sh dist.sh`.
