# ДЗ 10. Калькулятор: переменные, функции, документация

## Условие

Взять калькулятор с лекции (flex + bison) и расширить:

1. Переменные: `x = 5`, потом `2 * x`.
2. Функции: `sqrt(9)` — имя и скобки.
3. Ошибки ввода не роняют программу.
4. Все функции описаны через `@brief`.
5. Сайт собирается командой `doxygen Doxyfile`.
6. `report.txt`: что добавили, какие файлы правили.

Стандарт C11, сборка с `-Wall -Wextra -Werror`, `Makefile` с целями `all`, `test`, `docs`,
`clean`, `dist`. Структура отчёта: что добавили в грамматику, какие строки правили, примеры
работы, список страниц сайта, что было непонятно.

## Критерии

Базовый: `make clean && make` без предупреждений, калькулятор считает, сайт собирается.
Сделано: сборка идёт с `-Werror`, `make test` зелёный, `make docs` проходит с
`WARN_AS_ERROR = YES`.

Продвинутый: переменные и функции работают, приоритеты на месте, документация описывает каждую
публичную функцию, в отчёте есть «до и после». Сделано: переменные, пять функций (`sqrt`, `abs`,
`sin`, `cos`, `ln`), приоритеты проверены тестами, раздел 3 отчёта сравнивает с исходной версией.

Сверх условия: остаток `%` с проверкой нуля и степень `^`.

## Что где лежит

| Файл | Что это |
| --- | --- |
| `calc.l` | лексер: числа, имена, знаки; длинное имя режется и даёт ошибку; `\n` в конце ввода |
| `calc.y` | грамматика: выражения, присваивание, вызов функции, восстановление после ошибки |
| `calc.c`, `calc.h` | ошибки (одна на строку), вывод, `main`, вызовы таблиц из грамматики |
| `vars.c`, `vars.h` | таблица переменных: имя, значение, не больше 1024 штук |
| `funcs.c`, `funcs.h` | встроенные функции и проверка области определения |
| `test_vars.c`, `test_funcs.c` | модульные тесты двух модулей |
| `tests.sh` | сквозные тесты: вход и ожидаемый вывод `./calc` |
| `Makefile` | `make`, `make test`, `make docs`, `make clean`, `make dist` |
| `Doxyfile` | настройки сайта, сайт в `docs/html/` |
| `dist.sh` | собирает архив и делает `report.txt` из `REPORT.md` |
| `REPORT.md` | отчёт по структуре со слайда |
| `codegen-homework.tar.gz` | архив для сдачи: исходники и `report.txt` |

`lex.yy.c`, `calc.tab.c`, `calc.tab.h`, `docs/` и бинарники создаются при сборке и в
репозиторий и архив не попадают.

## Как собрать и запустить

В Ubuntu 24.04 нужны `build-essential`, `flex`, `bison`, `doxygen`:

```bash
sudo apt install build-essential flex bison doxygen
make clean && make
printf 'x = 5\n2 * x\nsqrt(9)\n' | ./calc
make test
make docs
```

Сайт открывается с `docs/html/index.html`. Те же сборка и тесты под ASan и UBSan:

```bash
make clean && make test SANITIZE=1
```

Что понимает калькулятор: числа с точкой, `+ - * / % ^`, унарный минус, скобки,
`имя = выражение`, `функция(выражение)`. Имя до 31 символа, переменных до 1024. Ошибка в
строке печатается один раз в stderr, строка пропускается, остальной ввод разбирается дальше.

## Как сделать архив

```bash
make dist
```

`make dist` запускает `dist.sh`: он превращает `REPORT.md` в `report.txt` (без markdown, таблицы
колонками), кладёт исходники и отчёт в папку `codegen-homework/` и пакует её в
`codegen-homework.tar.gz`. `make clean` убирает сборку, `docs/` и архив.
