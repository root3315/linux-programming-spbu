# ДЗ 9. Чат на двоих

## Условие

Сделать сервер и клиент на C, которые обмениваются строками по TCP:

1. Сервер принимает строку `имя: сообщение`.
2. Отвечает `привет, имя! ты сказал: сообщение`.
3. Считает сообщения и печатает счётчик в консоль.
4. Не падает на пустой строке и на очень длинной.
5. Клиент умеет отправить несколько сообщений подряд.
6. `report.txt`: как проверить, что всё работает.

Стандарт C11, сборка с `-Wall -Wextra -Werror` без предупреждений, `Makefile` с целями `clean`
и `dist`. Структура отчёта: как запустить сервер и клиент, вывод `ss` во время работы, что будет при
неверном порте, что было непонятно.

## Критерии

Базовый: сервер и клиент обмениваются сообщениями, ошибки обрабатываются, порт виден в `ss`.

Продвинутый: сервер обслуживает несколько клиентов подряд и не путает ответы, есть проверка длины
строки и понятная ошибка на плохой ввод.

## Что где лежит

| Файл | Что это |
| --- | --- |
| `chat_server.c` | сервер: `bind` на `127.0.0.1`, разбор строки, счётчик |
| `chat_client.c` | клиент: аргументы или stdin, несколько сообщений на одно соединение |
| `chat.h` | общее: `parse_port`, `send_all`, `MAX_LINE`, `MAX_NAME` |
| `Makefile` | `make`, `make clean`, `make dist` |
| `dist.sh` | собирает архив и делает `report.txt` из `REPORT.md` |
| `REPORT.md` | отчёт по структуре со слайда |
| `net-homework.tar.gz` | архив для сдачи: исходники и `report.txt` |

## Как собрать и запустить

В контейнере с Ubuntu 24.04:

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
apt update && apt install -y build-essential iproute2 netcat-openbsd
make
./chat_server 9100 &
./chat_client 127.0.0.1 9100 Степан "привет" "как дела"
ss -ltnp | grep 9100
```

Строки без клиента, в том числе пустую и слишком длинную, удобно слать через `nc`:

```bash
printf 'Вася:\n' | nc -N 127.0.0.1 9100
```

Правила протокола: строка до 512 байт, имя до 32 байт, `имя: сообщение` с двоеточием, пустые
имя и сообщение не принимаются. Счётчик считает только принятые сообщения. Порт: число
1–65535, иначе код выхода 2.

## Как сделать архив

```bash
make dist
```

`make dist` запускает `dist.sh`: он превращает `REPORT.md` в `report.txt` (без markdown, таблицы
колонками), кладёт исходники и отчёт в папку `net-homework/` и пакует её в `net-homework.tar.gz`.
`make clean` убирает бинарники и архив.
