# Практики занятия 9

Все четыре практики на примерах из архива Chapter 09 преподавателя: `echo_server.c`,
`echo_client.c`, `udp_echo.c`, `http_get.c` и `diag.sh`. Архив распаковал в `~/net-lab`.
В репозитории этих файлов нет, здесь только мои сессии с командами и выводом. Всё на
`127.0.0.1`, как на слайдах.

Запускал в контейнере с Ubuntu 24.04 (gcc 13.3.0):

```bash
docker run --rm -it -v "${PWD}:/work" -w /work ubuntu:24.04 bash
apt update && apt install -y build-essential iproute2 netcat-openbsd curl python3 strace
```

Архив в контейнер кладётся в `Chapter09/` рядом с папкой занятия. Файлы в архиве с концами
строк CRLF, перед сборкой перевожу их в LF: `sed -i 's/\r$//' *.c *.sh`.

## Практика 1. Осмотреть сеть

Пять команд: `ip -brief addr`, `ip route`, `ss -ltn`, `grep` по `/etc/services` и
`cat /etc/hosts`. Назвать свой адрес, шлюз и хотя бы одну программу, которая слушает порт.
В пустом контейнере слушать нечего, поэтому сам запускаю `python3 -m http.server`.

Решение: [01-inspect/session.md](01-inspect/session.md).

## Практика 2. Свой сервер и клиент

Собрать `echo_server` и `echo_client`, запустить сервер на 8080, позвонить клиентом, посмотреть
вывод сервера и `ss -ltnp | grep 8080`, потом позвонить на закрытый порт. Объяснить, чем `bind`
отличается от `connect` и почему сервер стартует первым. Заодно прогнал UDP-пример и `strace`.

Решение: [02-echo/session.md](02-echo/session.md).

## Практика 3. HTTP руками

Поднять `python3 -m http.server 8001` в каталоге с `index.html`, запросить страницу через
`http_get`, найти код ответа и `Content-Length`, запросить несуществующий файл и сравнить с
`curl -i`.

Решение: [03-http/session.md](03-http/session.md).

## Практика 4. Найти поломку

Пять поломок вместо одной, которую готовит преподаватель: сервер не запущен, сервер на другом
порту, порт занят, имя вместо адреса, не тот протокол на порту. Для каждой смотрю, какая проверка
из пяти находит причину быстрее всего.

Решение: [04-diagnose/session.md](04-diagnose/session.md).
